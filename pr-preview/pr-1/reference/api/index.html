    Core

    earthaccess_auth.login(strategy='all', persist=False, system=PROD)

    Authenticate with Earthdata Login (EDL) and return an Auth instance.

    Parameters:

    Name Type Description Default
    strategy str

    The authentication method.

    • "all": (default) Try, in order: environment variables, ~/.netrc, then an interactive prompt — stopping at the first one that works.
    • "interactive": Enter a username and password.
    • "netrc": Retrieve a username and password from ~/.netrc.
    • "environment": Retrieve either a username and password pair from the EARTHDATA_USERNAME and EARTHDATA_PASSWORD environment variables, or an Earthdata login token from the EARTHDATA_TOKEN environment variable.
    		 'all'
    persist bool

    Persist username and password credentials in a .netrc file.

    		 False
    system System

    The EDL endpoint to authenticate against. Defaults to PROD.

    		 PROD

    Returns:

    Type Description
    Auth

    An authenticated Auth instance. Hold onto it yourself — there's no
    Auth

    module-level singleton, so pass it to whatever needs it.

    earthaccess_auth.Auth(user_agent=None)

    Authentication class for operations that require Earthdata login (EDL).

    refresh_tokens()

    Refresh CMR tokens.

    CMR tokens authenticate queries for restricted and early-access datasets. This renews them so queries keep working for whatever collections the authenticated user has access to.

    DAAC registry

    earthaccess_auth.daac.DAACS module-attribute

    The registry of NASA Earthdata DAACs known to earthaccess-auth.

    Each entry is a DAACConfig describing one DAAC's short name, cloud/on-prem provider codes, and s3credentials endpoint. Look entries up with find_provider rather than scanning this list directly.

    Exceptions

    earthaccess_auth.LoginStrategyUnavailable

    Bases: Exception

    Raised when a login strategy couldn't be attempted at all.

    For example, the "environment" strategy raises this if none of EARTHDATA_USERNAME/EARTHDATA_PASSWORD/EARTHDATA_TOKEN are set. Contrast with LoginAttemptFailure, which is raised when a strategy was attempted but Earthdata Login rejected the credentials.

    earthaccess_auth.LoginAttemptFailure

    Bases: Exception

    Raised when Earthdata Login rejects an authentication attempt.

    For example, because the supplied username/password or token were invalid. Contrast with LoginStrategyUnavailable, which is raised when a strategy couldn't even be attempted (e.g. missing credentials).

    obstore (extra: earthaccess-auth[obstore])

    earthaccess_auth.adapters.obstore.s3_credential_provider(auth, credentials_endpoint)

    Build an obstore credential provider that refreshes EDL-issued S3 credentials.

    Hand this to obstore.store.S3Store(credential_provider=...) instead of a one-shot credentials dict, so a long-running job doesn't need its own refresh loop — the provider re-authenticates with EDL once the current credentials near expiry.
